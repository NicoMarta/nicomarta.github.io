Política de privacidad

M3D Automatización · Última actualización: 29 de septiembre de 2026

Qué es esta aplicación

M3D Automatización es una herramienta interna de M3D. Accede únicamente a la casilla de correo de M3D (impd3d@gmail.com) para procesar los comprobantes de pago de licencias de software que envían los clientes. No la usan terceros ni accede a cuentas de otras personas.

Qué datos usa

  • Los correos de esa casilla que traen archivos adjuntos: remitente, asunto y el adjunto (comprobante de pago en PDF o imagen).
  • De cada comprobante se extraen monto, fecha, número de operación, emisor y cliente.

Para qué se usan

  • Registrar el pago y emitir la licencia de software correspondiente.
  • Si el comprobante tiene algún problema, responderle al remitente desde la misma casilla, siempre con revisión y aprobación previa de M3D.

Con quién se comparten

Los datos no se venden ni se usan con fines publicitarios. Para leer el comprobante, el archivo adjunto se envía a un proveedor de inteligencia artificial (Anthropic, Claude) solo para extraer los datos del pago. Fuera de eso, no se comparten con nadie.

Dónde se guardan

Los datos extraídos se guardan en un servidor privado de M3D, sin acceso público.

Datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen con la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Contacto

Para consultas o para pedir la eliminación de tus datos, escribí a impd3d@gmail.com.
